## Selected Projects

### ⚖️ Legal AI: Retrieval & Chunking Research
**RAG over Indian legislation, comparing chunking strategies**

| | |
|---|---|
| **Problem** | How much does the chunking strategy affect retrieval quality on legal text? |
| **Approach** | Three chunking methods (semantic, fixed-size, recursive), each embedded into its own Qdrant collection, with LLM-based answer generation |
| **Stack** | Python · OpenAI Embeddings · Qdrant · Ollama · PyMuPDF |
| **Code** | [GitHub Repository](https://github.com/siraman0177/Legal-AI-research_paper) |

| | |
|---|---|
